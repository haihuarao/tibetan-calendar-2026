打开独立的 🐟 订阅页

iPhone 添加方法（安全 HTTPS）

  1. 点击“复制 HTTPS 订阅地址”。
  2. 打开“设置 → 日历 → 账户 → 添加账户 → 其他 → 添加已订阅的日历”。
  3. 粘贴复制的 HTTPS 地址。
  4. 保存后在账户中确认日历已启用。

不要使用 webcal:// 链接；部分 iPhone 版本会把它当作非加密连接并提示“不安全连接”。请始终使用 HTTPS 地址。

也可以手动添加

  1. 打开“设置 → 日历 → 账户 → 添加账户 → 其他”。
  2. 选择“添加已订阅的日历”。
  3. 服务器地址填入 calendar-2026.ics。
  4. 点击“下一步”并保存。
